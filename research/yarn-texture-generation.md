# Wool texture for the crochet study

The built-in image-generation tool created this material asset using the supplied carpet photograph as a reference. It is an illustration texture, not additional project photography.

- Reference: `assets/originals/crochet-carpet.png`
- Generated original: `assets/originals/yarn-fiber-generated.png`
- Web texture: `assets/images/yarn-fiber-texture.jpg` (384 × 384 JPEG)
- Use: embedded in SVG patterns, tinted to the three existing yarn colors. The downloaded pattern contains its texture without an external image request.
- Encoding: `sips`, JPEG quality 80, maximum dimension 384. The generated original is preserved.

## Prompt

Use case: photorealistic-natural. Asset type: seamless material texture tile for soft chunky yarn in an interactive crochet illustration. Input image: the brown carpet photograph is a MATERIAL REFERENCE ONLY. Create a square edge-to-edge macro texture of its soft matte spun wool fibres. Show tiny irregular fibrous strands and fine soft hairs, densely filling the entire image. Neutral warm grayscale, very light grey base with gentle mid-grey fibre details, low contrast, diffuse even lighting, no cast shadows. No recognisable crochet stitches or motif, no holes or gaps, no floor, no rug, no visible background, no UI, no letters, no border. The image will be tiled and clipped into thick curved yarn strokes, so the fibre scale should be small, even, and not directional. Keep natural soft fuzz, avoid glossy rope, plastic, embossed pattern, high contrast grain, or a large-scale weave. Output one seamless square texture, no margins. Preserve the reference photo itself; create a separate material asset.
